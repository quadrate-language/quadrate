# Higher-Order Functions

Demonstrates functional programming combinators from the `hof` module.

## Run

```bash
quad run hof.qd
```

## Features

- `bi` - Apply two functions to the same value
- `keep` - Apply function but preserve original
- `dip` - Apply to second element, preserve top
- `both` - Apply same function to two values
- `when/unless` - Conditional application
- `times` - Apply function n times
- Anonymous functions (lambdas)

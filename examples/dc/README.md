# dc

Desk calculator clone - a reverse-polish notation calculator.

## Run

```bash
quad run dc.qd
```

## Usage

```
5 3 + p    # prints 8
10 2 / p   # prints 5
q          # quit
```

## Features

- Interactive REPL
- Standard library usage (`flag::`, `io::`, `mem::`, etc.)
- Command-line argument parsing
- File I/O

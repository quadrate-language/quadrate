# Lambdas

Demonstrates anonymous functions (lambdas) and first-class functions.

## Run

```bash
quad run lambdas.qd
```

## Features

- Anonymous function syntax: `fn (x:i64 -- r:i64) { ... }`
- Storing functions in variables
- Calling functions with `call`
- Functions with multiple parameters
- Side-effect functions (no return value)

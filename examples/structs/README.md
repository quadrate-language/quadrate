# Structs

Demonstrates structs, methods, and constants.

## Run

```bash
quad run structs.qd
```

## Features

- Struct definitions
- Struct construction
- Field access (`<<field`)
- **Struct methods** with receiver syntax (`fn (p:Point) methodName(...)`), the receiver bound to
  its name and the other inputs left on the stack
- Method calls on struct values
- Constants
- `math::` module usage

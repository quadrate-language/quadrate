# quadlsp

Language Server Protocol server for Quadrate.

## Usage

```bash
quadlsp
```

Communicates via stdin/stdout using JSON-RPC.

## Features

- Syntax diagnostics
- Auto-completion (built-in instructions)
- Document formatting

## Editor integration

Configure your editor to use `quadlsp` as the language server for `.qd` files.

- **Neovim**: https://github.com/quadrate-language/quadrate.nvim
- **VS Code**: https://github.com/quadrate-language/quadrate-vscode

All Modules

net

TCP network operations. Error codes: Ok=1 (success), specific errors start at 2

Constants

ErrListen = 2
Error: Listen/bind failed.
ErrAccept = 3
Error: Accept failed.
ErrConnect = 4
Error: Connection failed.
ErrSend = 5
Error: Send failed.
ErrReceive = 6
Error: Receive failed.
ErrInvalidArg = 7
Error: Invalid argument.
ErrTimeout = 8
Error: Timeout setting failed.
ErrLookup = 9
Error: DNS lookup failed.

listen [fallible]

fn listen(port:i64 -- socket:i64)!

Start listening for connections on a port.

Parameters:

port i64
Port number to listen on

Returns:

socket i64

Errors:

ErrListen
Port may be in use or permission denied

Examples:

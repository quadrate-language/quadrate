Quadrate API

All Modules

regex

Regular expression matching using Thompson NFA. Supports . * + ? | () [] [^] [a-z] ^ $ and escapes. Note: Nested groups and alternation inside groups not yet supported.

find_all

fn (self:Regex) find_all(s:str max:i64 -- results:ptr count:i64)

Find all non-overlapping matches. Returns array of start/end pairs and count. Caller must free the returned array with mem::free.

Parameters:

self Regex
s str
String to search
max i64
Maximum matches to find (-1 for unlimited)

Returns:

results ptr
Array of i64 pairs [start0, end0, start1, end1, ...]
count i64
Number of matches found

Examples:

"[0-9]+" regex::compile -> re  re "a1b22c333" -1 regex::find_all -> count -> results

Calls: mem::alloc, mem::copy, mem::free, mem::set_i64

hex

Hexadecimal encoding and decoding. Converts between binary data and hexadecimal string representation.

Functions

encode

fn encode(s:str -- hex:str)

Encode a string to uppercase hexadecimal. Each byte becomes two hex characters (00-FF).

Parameters:

s str
String to encode

Returns:

hex str
Hexadecimal string (uppercase)

Examples:

"Hello" hex::encode -> "48656C6C6F"

Calls: mem::alloc, mem::free, mem::set_byte, mem::to_string, strings::char_at, strings::len

decode

fn decode(hex:str -- s:str)

Decode a hexadecimal string to bytes. Accepts both uppercase and lowercase hex digits. Invalid characters are skipped.

Parameters:

hex str
Hexadecimal string

Returns:

s str
Decoded string

Examples:

"48656C6C6F" hex::decode -> "Hello"

Calls: mem::alloc, mem::free, mem::set_byte, mem::to_string, strings::char_at, strings::len

Called by: crypto::hmac_sha256, crypto::hmac_sha512, hmac::hmac_sha256, hmac::hmac_sha512

is_valid

fn is_valid(hex:str -- valid:i64)

Check if a string contains only valid hexadecimal characters. Valid characters are 0-9, A-F, a-f.

Parameters:

hex str
String to check

Returns:

valid i64
1 if valid hex, 0 otherwise

Examples:

"48656C6C6F" hex::is_valid -> 1
"48ZZ" hex::is_valid -> 0

Calls: strings::char_at, strings::len

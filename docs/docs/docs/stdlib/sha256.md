# sha256

SHA-256 cryptographic hash function.
Produces a 256-bit (32-byte) hash value.
Conforms to FIPS 180-4.

## Functions

### hash

Calculate SHA-256 hash of a string.

**Signature:** `( s:str -- result:str )`

---

### hash_bytes

Calculate SHA-256 hash of raw bytes.

**Signature:** `( buf:ptr length:i64 -- result:str )`

| Parameter | Type | Description |
|-----------|------|-------------|
| `buf` | `ptr` | Input buffer |
| `length` | `i64` | Length of buffer in bytes |

| Output | Type | Description |
|--------|------|-------------|
| `hash` | `str` | 64-character hex string (lowercase) |

---

### hash_raw

Calculate SHA-256 hash and return as raw 32-byte buffer.

**Signature:** `( s:str -- buf:ptr )`

---

### verify

Verify a string against an expected SHA-256 hash.

**Signature:** `( s:str expected:str -- ok:i64 )`

deque

Deque<T> - A Double-Ended Queue ================================ Deque provides O(1) push/pop from both ends. Implemented using a circular buffer. ## Creating a Deque Create an empty deque: Deque<i64> { data = null head = 0 tail = 0 len = 0 cap = 0 } -> d ## Basic Operations Push to front/back: d 42 push_front! -> d d 42 push_back! -> d Pop from front/back: d pop_front! -> d -> val d pop_back! -> d -> val Peek front/back: d peek_front! -> val d peek_back! -> val ## Memory Management Always call release when done: d release

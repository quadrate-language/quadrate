md5

MD5 Implementation ================== MD5 hash with streaming and one-shot APIs. Note: MD5 is cryptographically broken. Use only for checksums, not security. use crypto // One-shot "Hello" md5! -> hash // Streaming Md5 {} -> h h "Hello" update! -> h h " World" update! -> h h finish! -> hash h release

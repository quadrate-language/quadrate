Runtime information and version constants. Provides version information about the Quadrate runtime.

Functions

version

fn version( -- version:str)

Get the Quadrate version string.

Returns:

version str
Version string (e.g., "2.0.0-alpha")

Examples:

rt::version print nl  // 2.0.0-alpha

fn version_api( -- api:i64)

Get the Quadrate API version number. Encoded as: major * 10000 + minor * 100 + patch.

Returns:

api i64
API version number (e.g., 20000 for v2.0.0)

Examples:

rt::version_api print nl  // 20000

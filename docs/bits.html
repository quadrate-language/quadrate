mask

fn mask(i64 i64 -- result:i64)

Bitwise operations for integer manipulation. Core operations (and, or, xor, not, shl, shr) are builtins. This module provides higher-level bit manipulation functions. Keep only the bottom N bits.

Parameters:

value i64
Input value
num_bits i64
Number of bits to keep from LSB

Returns:

result i64
Masked value

Examples:

0xFF 4 bits::mask print  // 15

Called by: bits::extract, bits::rotate_left, bits::rotate_right, bits::set_bits, crc32::value, crypto::value

hmac

HMAC (Hash-based Message Authentication Code) ============================================= HMAC-SHA256 and HMAC-SHA512 implementations per RFC 2104. use crypto "my-secret-key" "Hello World" hmac_sha256! -> mac mac print // prints 64-char hex HMAC

queue

Queue<T> - A FIFO Queue ======================== Queue provides First-In-First-Out (FIFO) operations. Implemented using a circular buffer for O(1) enqueue/dequeue. ## Creating a Queue Create an empty queue: Queue<i64> { data = null head = 0 tail = 0 len = 0 cap = 0 } -> q ## Basic Operations Enqueue (add to back): q 42 enqueue! -> q Dequeue (remove from front): q dequeue! -> q -> val Peek (view front without removing): q peek! -> val ## Memory Management Always call release when done: q release

hof

Higher-Order Function combinators. Combinators are functions that combine or apply other functions in useful patterns. They enable functional programming without explicit temporary variables.

Functions

fn apply(x:i64 f:fn(i64 -- i64) -- r:i64)

Apply a function to a value.

Parameters:

x i64
The input value
f fn(i64 -- i64)
-- i64) Function (i64 -- i64)

Returns:

r i64

Examples:

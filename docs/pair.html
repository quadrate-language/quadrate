Pair<T, U> - A Generic Two-Element Tuple ======================================== Pair holds two values of potentially different types. Useful for returning multiple values or key-value associations. ## Creating a Pair Pair<i64, str> { first = 42 second = "hello" } -> p ## Accessing Elements p <<first -> key p <<second -> value ## Unpacking Both Elements p unpack -> a -> b

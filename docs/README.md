# Quadrate Documentation

This directory contains the Quadrate documentation built with MkDocs.

## Setup

Create a virtual environment and install dependencies:

```bash
cd docs
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Building

Build the static site:

```bash
mkdocs build
```

The output will be in `site/`.

## Development

Run a local development server with live reload:

```bash
mkdocs serve
```

Then open http://127.0.0.1:8000 in your browser.

## Structure

- `docs/` - Markdown source files
  - `docs/learn/` - Tutorial sections (1-8)
  - `docs/reference/` - Language reference (keywords, builtins)
  - `docs/stdlib/` - Standard library documentation
- `pygments-quadrate/` - Custom syntax highlighter for Quadrate
- `api/` - JSON API docs (generated by scripts/gen_docs.py)
- `mkdocs.yml` - MkDocs configuration

## Regenerating Stdlib Docs

Standard library documentation is generated from source:

```bash
cd ..
python scripts/gen_docs.py
```

## Syntax Highlighting

The `pygments-quadrate` package provides syntax highlighting for Quadrate code blocks. It's installed automatically with the requirements.

Use `qd` as the language identifier in code blocks:

````markdown
```qd
fn main( -- ) {
    "Hello" print nl
}
```
````

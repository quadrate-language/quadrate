# qdmem

Memory management (`mem::` module).

## Overview

Direct memory allocation and manipulation for low-level programming.

## Key functions

- `alloc`, `realloc` - Allocation
- `get_byte`, `set_byte` - Byte access
- `get_i64`, `set_i64` - Integer access
- `get_f64`, `set_f64` - Float access
- `get_ptr`, `set_ptr` - Pointer access
- `copy`, `zero`, `fill` - Bulk operations
- `to_string`, `from_string` - Conversions

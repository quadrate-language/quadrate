# qdstr

String manipulation functions (`str::` module).

## Overview

String operations including length, search, concatenation, and case conversion.

## Key Functions

- `len`, `concat`, `substring` - Basic operations
- `contains`, `starts_with`, `ends_with`, `index_of` - Search
- `upper`, `lower`, `trim` - Transformation
- `split`, `replace` - Advanced operations
- `char_at`, `from_char`, `compare` - Character operations

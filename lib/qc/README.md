# qc

Compiler frontend library for Quadrate.

## Overview

Provides parsing, AST representation, semantic analysis, and error reporting. Used by the compiler and language tools.

## Key Components

- **parser** - Converts source code to AST
- **ast** - Typed AST node classes
- **semantic_validator** - Type checking and validation
- **error_reporter** - Colorized diagnostic messages
- **formatter** - Code formatting logic
